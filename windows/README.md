# Fox VPN برای ویندوز

همان برنامهٔ لینوکس (Swing) با تونل کل سیستم: `hev-socks5-tunnel` + درایور **Wintun**، مسیرها و DNS با PowerShell.

- نصب: `FoxVPN-Setup-*.exe` (یا نسخهٔ پرتابل `FoxVPN-portable.zip`: `FoxVPN\FoxVPN.exe`).
- برنامه همیشه با **Administrator** اجرا می‌شود (UAC)؛ برای ساخت کارت مجازی و مسیرها لازم است.
- ویندوز ۱۰/۱۱ ۶۴بیتی. Java جداگانه لازم نیست (داخل برنامه است).
- فایل‌ها: تنظیمات `%APPDATA%\FoxVPN`، لاگ و وضعیت `%LOCALAPPDATA%\FoxVPN\run` (`engine.log`, `hev.log`, `engine.out`).

## چطور کار می‌کند
1. موتور SSH (`Engine`) جدا اجرا می‌شود و SOCKS محلی می‌سازد (همان منطق لینوکس: بایپس ایران، تانل‌ها، UDP).
2. مسیر مستقیم به خود سرور SSH از کارت اصلی اضافه می‌شود.
3. `hev-socks5-tunnel` کارت `FoxVPN` (Wintun) را می‌سازد؛ مسیرهای `0.0.0.0/1` و `128.0.0.0/1` و DNS روی آن تنظیم می‌شوند.
4. اتصال‌های مستقیم (بایپس ایران) به IP کارت اصلی bind می‌شوند تا وارد تونل نشوند.
5. قطع/بستن: پردازش‌ها بسته می‌شوند و مسیرها با حذف کارت پاک می‌شوند.

## محدودیت‌ها
- فقط IPv4 داخل تونل (مثل لینوکس).
- DNS روی کارت تونل تنظیم می‌شود؛ ویندوز ممکن است برای بعضی نام‌ها هم‌زمان از کارت‌های دیگر بپرسد.
- آنتی‌ویروس‌ها گاهی `wintun.dll` را هشدار می‌دهند (درایور رسمی wintun.net).
