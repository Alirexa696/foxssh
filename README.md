# Fox SSH — کلاینت VPN روی SSH برای اندروید

ویژگی‌ها: اتصال SSH ساده (رمز عبور) + tun2socks (hev) + UDP از طریق badvpn-udpgw؛
نمایش بنر SSH سرور به‌صورت پاپ‌آپ؛ لیست IP ایران (دانلود خودکار هفتگی + نسخهٔ داخل برنامه)
و افزودن دستی IP/CIDR/دامنه؛ ترافیک این مقصدها **مستقیم** می‌رود و در «ترافیک تونل» حساب نمی‌شود.

## ساخت APK (بدون نصب چیزی روی کامپیوتر)
1. پروژه را در یک مخزن GitHub (خصوصی) بگذارید و push کنید.
2. تب Actions → «Build APK» → Run workflow. بعد از چند دقیقه فایل APK در Artifacts است.
3. برای اینکه نسخه‌های بعدی روی قبلی نصب شوند: `tools/make_keystore.sh` را یک بار اجرا و ۴ مقدار را در Secrets بگذارید
   (KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD). بدون آن، با کلید debug امضا می‌شود.

## لوگو و نام
- `python3 -m pip install pillow` سپس `tools/set_logo.sh logo.png` (PNG مربع).
- نام برنامه: `app/src/main/res/values/strings.xml` ← `app_name`.

## سمت سرور
- بنر: در `/etc/ssh/sshd_config` خط `Banner /etc/ssh/banner.txt` و ری‌استارت sshd. بدون بنر، چیزی نمایش داده نمی‌شود.
- UDP: badvpn-udpgw روی 127.0.0.1 با پورت دلخواه (پیش‌فرض 7300) و همان پورت را در برنامه بزنید؛ خالی/۰ = غیرفعال.
- `AllowTcpForwarding yes` لازم است.

## محدودیت‌ها
- بایپس فقط IPv4 است؛ IPv6 داخل تونل می‌رود.
- بایپس دامنه با تبدیل به IP انجام می‌شود (هر ۱۰ دقیقه تازه می‌شود).
- رمز ورود به‌صورت ساده در حافظهٔ خصوصی برنامه ذخیره می‌شود (گزینهٔ «ذخیره» را بردارید تا ذخیره نشود).
